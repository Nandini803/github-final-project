# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to this project!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes before submitting them.
5. Commit your changes with a clear message.
6. Create a Pull Request.

## Guidelines

- Keep the code simple and readable.
- Use clear variable and function names.
- Add comments where necessary.
- Make sure the program works correctly before submitting changes.
- Be respectful to other contributors.

## Reporting Issues

If you find a bug or have a suggestion, create an issue in the GitHub repository and clearly explain the problem or suggestion.

Thank you for contributing!
