# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone.

## Expected Behavior

- Be respectful and polite.
- Accept constructive feedback.
- Focus on the project and its goals.
- Help other contributors when possible.

## Unacceptable Behavior

- Harassment or discrimination.
- Offensive or disrespectful comments.
- Personal attacks.
- Any behavior that creates an unsafe environment.

## Enforcement

Project maintainers may take appropriate action if this code of conduct is violated.

Thank you for helping maintain a friendly and respectful project.
